# Agent 决策绩效评估与权重计算 Skill (Agent Executive Performance & Weighting)

## 1. 概述 (Overview)
本 Skill 用于评估参与决策的官员 Agent 在每个**决策周期**内的综合表现。**核心适配场景**：当单个周期内发生多次独立皇帝决策（`E1, E2, ..., En`）时，本 Skill 通过统计官员与皇帝决策的**整体一致性比率**，并结合该周期的**最终净资产变化**，来判定官员本周期是否应被记为 **差评**，最终按比例更新下一轮各官员 Agent 的决策权重。

---

## 2. 基础数据与指标定义 (Definitions)

### 2.1 净资产与周期结果
*   **周期净资产**：
    $$\text{净资产} = \text{现金} + \text{所有地产总价} + \text{所有房产总价} - \text{抵押欠款}$$
*   **周期净资产变化 ($\Delta$)**：
    $$\Delta = \text{周期末净资产} - \text{周期初净资产}$$
*   **结果判定**：
    *   **好结果** ($\Delta \ge 0$)：周期内净资产未减少（保值或增值）。
    *   **坏结果** ($\Delta < 0$)：周期内净资产减少（亏损）。

### 2.2 多决策统计指标 `[v2.0 新增]`
设本周期内，皇帝共做出了 **`N`** 次独立最终决策（`E1` 至 `EN`）。
*   **官员一致次数 (`C`)**：在该周期 `N` 次决策中，该官员 Agent 提议方向与皇帝最终决策 **相同（一致）** 的次数。
*   **一致率 (`P`)**：
    $$P = \frac{C}{N}$$
    （`P` 的取值范围为 0 到 1，反映该官员在本周期内附和皇帝的程度）。

### 2.3 门下省放行决议逻辑
*   **中书省最初决策 `Zi`**：指经中书省提出的决议。
*   **官员投票类型**：门下省官员 Agent 在每次决策中可选择 **“通过”（赞同）** 或 **“反对”（不赞同）**；若未投票或弃权，视为“反对”。
*   **皇帝最终决策 `Ei`**：指经皇帝确认并实际执行的决议（已生效）。
*   **一致性判定**：
    *   **与中书省一致** —— 该官员对决议 `Zi` **投了“通过”票**。
    *   **与中书省不一致** —— 该官员对决议 `Zi` **投了“反对”票**（或弃权、未投票）。

|                 | 皇帝与中书省一致  | 皇帝与中书省不一致 |
| :-------------- | :---------- | :------------ |
| **拒绝**        | 不一致      | 一致          |
| **接受**        | 一致        | 不一致      |

## 3. 差评判定逻辑

在执行完本周期所有皇帝决策 `E1...EN`，并结算最终周期净资产变化 `Δ` 后，按以下规则判定官员 Agent 本周期是否被记为 **差评**：

| 周期最终结果 | 一致率 (P) 阈值 | 差评判定 | 逻辑依据与原则 |
| :--- | :--- | :--- | :--- |
| **坏结果** ($\Delta < 0$) | **P ≥ 50%**（多数时候附和） | **记为差评** | 整体方向错误，且该官员多数情况下随波逐流、未能阻止亏损，需承担集体决策失误责任。 |
| **坏结果** ($\Delta < 0$) | **P < 50%**（多数时候反对） | **不记差评** | 虽然最终亏损，但该官员在大部分关键时刻投了反对票，表现出独立的避险意识，予以免责。 |
| **好结果** ($\Delta \ge 0$) | **P < 50%**（多数时候反对） | **记为差评** | 最终整体盈利，但该官员在大部分决策中与正确方向背道而驰，存在战略阻碍或判断严重失误。 |
| **好结果** ($\Delta \ge 0$) | **P ≥ 50%**（多数时候附和） | **不记差评** | 整体方向正确，且该官员多数情况下顺应大势支持了正确决策，予以肯定及免责。 |

## 4. 执行流程示例 (Execution Workflow Example)

> **场景设定**：全局共有 A、B 两位官员 Agent。

### 周期 1（多决策场景）
*   **皇帝决策序列**：本周期内皇帝共做出 **3 次** 独立决策（`E1`=买地，`E2`=卖房，`E3`=贷款）。
*   **周期最终结果**：执行完所有决策后，周期末结算 $\Delta = -200,000$（**坏结果**）。
*   **官员投票详情**：
    *   **Agent A**：E1(一致)，E2(不一致)，E3(一致) $\Rightarrow$ 一致次数 `C=2`，总决策 `N=3`，**一致率 P = 2/3 ≈ 66.7%**。
    *   **Agent B**：E1(不一致)，E2(不一致)，E3(一致) $\Rightarrow$ 一致次数 `C=1`，总决策 `N=3`，**一致率 P = 1/3 ≈ 33.3%**。

*   **差评判定（查第 3 节表格）**：
    *   **Agent A**：最终结果为**坏**，且 `P=66.7% ≥ 50%` $\Rightarrow$ **记为差评**。（随大流导致亏损）
    *   **Agent B**：最终结果为**坏**，且 `P=33.3% < 50%` $\Rightarrow$ **不记差评**。（多数时候在反对，免责）
